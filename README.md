# 🎲 Dice Roller

A simple interactive dice roller built with HTML, CSS, and JavaScript.

## Features

- 🎲 Random dice rolls
- 🔢 Roll counter
- 📜 Roll history
- 🔟 Keeps the last 10 rolls
- 🗑️ Clear history button
- 💫 Dice roll animation
- 🖱️ Hover effects
- 📱 Responsive design

## What I Practiced

- DOM manipulation
- Event listeners
- JavaScript functions
- Arrays
- `Math.random()`
- `Math.floor()`
- Template literals
- Creating HTML elements with JavaScript
- Updating page content dynamically
- CSS animations and transitions
